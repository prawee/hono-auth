# Hono IAAA

Practise about IAAA with Hono and friend stack

## Stack
- Hono
- REST Client (VSCode Extension)
- PostgreSQL
- Drizzle ORM
- Better Auth

## Initial
To install dependencies:
```sh
bun install
```

To using db:
```sh
bun run db:up
```

To run:
```sh
bun run dev
```

open http://localhost:3000
